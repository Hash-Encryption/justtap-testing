## Configuration conflicts requiring deliberate resolution

- `package.json`: `dev`/`build` run Next, while `dev:vite`/`build:vite` run V2.
- `tsconfig.json`: includes legacy trees and excludes `src/**/*`.
- `next.config.mjs`: static export to `out`.
- `wrangler.json`: expects `out`.
- `vite.config.ts`: TanStack Start/Nitro with Cloudflare Pages server output.
- `.lovable/project.json`: TanStack Start template.
- `src/routes/README.md`: states TanStack file routing and forbids `app/layout.tsx`, which still exists in the frozen legacy tree.

## Items intentionally not removed in Phase 00

- all Next.js application files and dependencies;
- `generateStaticParams()` implementations;
- `/c/* -> /c.html` redirect;
- legacy and TanStack demo remnants;
- duplicate public card, vCard, Wallet, dashboard, and admin code;
- mutable `supabase/schema.sql` and current RLS policies.

They remain visible so later phases can migrate or remove them with evidence instead of assumption.
