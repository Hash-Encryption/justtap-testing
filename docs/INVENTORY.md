## Configuration conflicts requiring deliberate resolution

- `package.json`: default scripts now run V2; explicit legacy aliases remain until Phase 14.
- `tsconfig.json`: includes legacy trees and excludes `src/**/*`; `tsconfig.v2.json` is the V2 validation config.
- `next.config.mjs`: static export to `out`.
- `wrangler.json`: expects the verified V2 `dist` artifact.
- `vite.config.ts`: TanStack Start/Nitro with Cloudflare Pages server output.
- `.lovable/project.json`: TanStack Start template.
- `src/routes/README.md`: states TanStack file routing and forbids `app/layout.tsx`, which still exists in the frozen legacy tree.

## Items intentionally retained after Phase 01

- all Next.js application files and dependencies;
- the legacy Wallet implementation and its static-parameter helper for Phase 12 migration review;
- duplicate Wallet, dashboard, and admin code scheduled for later phases;
- mutable `supabase/schema.sql` and current RLS policies.

They remain visible so later phases can migrate or remove them with evidence instead of assumption. Legacy public-card routes, renderer components, vCard route, and `c.html` redirect were removed in Phase 01.
